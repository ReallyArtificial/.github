# Contributing to Really Artificial

We love your input! This repository contains organization-wide community health files and templates for Really Artificial projects.

## What's in This Repo

- Organization profile README
- Community health files (CODE_OF_CONDUCT, CONTRIBUTING, SECURITY)
- Issue and PR templates (standardized across all projects)
- GitHub Actions workflows (reusable across projects)

## Making Changes

1. Fork the repo and create your branch from `main`
2. Make your changes to org-wide files
3. Test templates in a test repository if applicable
4. Issue that pull request!

## Pull Request Process

1. **Before submitting:**
   - Ensure templates work across different project types
   - Keep language general enough for all Really Artificial projects
   - Test issue/PR templates in a real repository

2. **PR Guidelines:**
   - Explain the reasoning behind template changes
   - Consider impact on all Really Artificial repositories
   - Follow existing formatting and structure

## What to Contribute

### Useful Contributions

- Improvements to issue/PR templates
- Better community health files
- Reusable GitHub Actions workflows
- Documentation for org-wide standards

### Before Contributing

- Check if other Really Artificial repos would benefit
- Consider backwards compatibility
- Discuss major changes in an issue first
